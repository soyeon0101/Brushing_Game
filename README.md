# 닦아줘! 프렌즈 (Brushy Galaxy)

## 구현된 기능

- **첫 실행**: 타이틀, 보호자 동의(개인정보·카메라), 회원가입(보호자 이름·이메일), 나이 선택, 캐릭터 선택(공주/왕자), 닉네임 입력
- **양치 사진 액자**: 양치 중 구역마다 사진 1장(모두 4장), 치료 후 액자 4종에 담아 보여줌. 사진은 기기에만 저장
- **우주 항해 지도 / 파트너 방**: 도장마다 발판이 켜지고 행성이 열림, 로봇 친구 깨우기·이름 짓기·밥 주기
- **로비**: 프로필, 오늘의 스티커, 오늘의 환자
- **치료 흐름**: 오늘의 환자, 카메라 준비(3초 카운트다운), 로딩, 4구역 양치, 치료 완료(전/후 비교)
- **양치**: 구역별 줌인, 요정 vs 충치균 전투, 구역 타이머, 응원/멈춤/과속 안내, 손 인식 실패 안내, 카메라 작은 창, 일시정지, 소리 켜기/끄기
- **스티커판**: 주간 × 아침/점심/저녁, 도장 연출
- **환자 도감**: 치료한 환자 열림
- **보호자 설정**: 탭 구성 (사운드: 전체/배경음/효과음 볼륨·음소거, 음성 안내 / 게임 설정: 구역당 양치 시간 10~60초 입력, 기록 초기화)
- **저장**: 프로필, 설정, 스티커, 도감, 치료 횟수
- **손 인식**: 전면 카메라, 양치/과속 판정
- **키보드 테스트 입력**: F2로 전환 (Space 양치, Shift 과속, H 손 숨김)

## 업데이트 기록

### v0.3 (2026-10-27)
- **보호자 동의·회원가입**: 첫 실행 때 [필수] 개인정보 수집·이용, [필수] 카메라 권한 이용 동의 → 보호자 이름·이메일 가입. 가입 정보는 기기에만 저장 (예전 저장 데이터는 동의·가입만 받고 로비로)
- **양치 사진 액자**: 양치 중 구역마다 사진 1장씩 촬영(찰칵 번쩍임) → 치료 완료 후, 칭찬 도장 전에 사진 4장을 액자에 담아 보여줌
  - 액자 4종, 사진 배치도 제각각: 딸기우유(하트), 반짝우주(행성 창문), 민트거품(큰 사진 + 방울), 무지개(폴라로이드 콜라주). 고른 액자 기억
  - **사진은 기기 안에만 저장되고 서버로 보내거나 저장하지 않음**. 보호자 설정 초기화로 사진까지 삭제
- **공주·왕자 캐릭터 새 그림**: 게임 분위기(말랑한 파스텔 3D)에 맞춰 교체
- **우주 항해 지도** (반짝 배지 버튼 자리): 받은 도장마다 발판이 켜지고 행성 잠금 해제 애니메이션
- **파트너 방** (스티커판 버튼 자리): 로봇 친구 데려오기, 첫 양치로 깨우기, 이름 짓기, 밥 주기

### 2026-10-01
- **사운드**: 배경음(기본/양치), 버튼 터치·가글·클리어 효과음. 일시정지하면 배경음도 멈춤
- **캐릭터별 전투 친구**: 공주는 토끼, 왕자는 공룡
- **보호자 설정**: 배경음 / 효과음 따로 켜기·끄기
- **환자 5종 양치 화면**: 블루·핍·렉스·올리·노바 얼굴/입 그림 추가. 환자별로 입 크기·위치와 이빨 위치를 맞춤
- **보호자 설정 개편**: 사운드 / 게임 설정 탭으로 분리 (탭 추가 가능 구조)
  - 사운드: 볼륨 슬라이더 + 음소거
  - 게임 설정: 양치 시간 숫자 입력(10~60초, 기본 20초), 변경 확인 팝업, 우측 하단 초기화
  - 설정창 그림: 액자 판, 줄 아이콘, UFO 슬라이더
- **정리**: 쓰지 않는 3D 캐릭터(모델·코드), 그림 원본(ArtDrafts), 안 쓰는 폰트·그림 삭제 (별도 zip 백업)

## 코드 구조

```
[MediaPipe 결과 콜백]
  → HandFrameBuffer    스레드 안전 좌표 버퍼
  → BrushDetector      흔들림 판정 (방향 반전 → 양치 / 과속 / 칫솔질 횟수)
  → IBrushInput        CameraBrushInput / KeyboardBrushInput
  → BrushInputHub      화면들이 보는 단일 입력 (F2로 전환)
  → BrushingScreen     구역 진행, 안내 문구
      → MouthZoom / BrushZoneView / BattleView   줌, 구역 연출, 전투 연출

GameFlow  화면 전환의 유일한 기준 (화면은 버튼 이벤트만 알림)
SaveStore 저장 파일 읽기/쓰기
```

| 폴더 (`Assets/BrushGame/`) | 내용 |
|---|---|
| `Scripts/Core` | 화면 흐름(`GameFlow`), 콘텐츠 목록(`GameCatalog`), 저장 |
| `Scripts/Screens` | 화면별 스크립트, 보호자 설정 창 |
| `Scripts/Game` | 양치 화면 연출 (줌, 구역, 전투) |
| `Scripts/HandTracking` | MediaPipe Runner, 좌표 버퍼, 양치 판정, 개발용 표시 |
| `Scripts/Input` | 입력 인터페이스, 키보드 입력, 입력 전환 |
| `Scripts/UI` | 그림 자리, 카메라 영상 맞춤, 세로 화면/safe area, 공용 UI |
| `Editor` | 씬 생성, UI 스킨, 폰트, 크로마키 처리, 그림 가져오기 설정 |
| `Data` | `GameCatalog.asset` (캐릭터, 환자 목록) |
| `Art`, `Fonts` | 그림, 폰트 |

## 주요 조정 값

판정 값은 임시 값이며, 아이들로 다시 측정한 뒤 확정해야 합니다.

| 위치 | 값 | 현재 |
|---|---|---|
| 보호자 설정 | 구역당 양치 시간 | 기본 20초 (10~60초 입력) |
| `BrushingScreen` | 과속 중 진행 속도 배율 | 0.4 |
| `BrushingScreen` | 손 안 보임 안내까지 시간 | 1.5초 |
| `BrushingScreen` | 반짝이 한 번에 필요한 칫솔질(방향 전환) | 4 |
| `BrushDetector` | 양치 기준 / 과속 기준 (초당 방향 반전) | 1.5 / 10 |
| `BrushDetector` | 이보다 작은 손 무시 | 0.08 |
